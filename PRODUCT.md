# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

(Rendered inside a Tauri v2 WKWebView on macOS only. The design language is a desktop Mac app, not a website.)

## Stack

Rust core + Tauri v2, UI in Svelte 5 + Vite + TypeScript, plain CSS with tokens, npm. Chosen by the user.

## Users

One person on their own Mac who uses WhatsApp daily and wants to read and answer without leaving what they are doing, with a local AI that can draft, answer for them, and act on request. Spanish and English speakers.

## Product Purpose

Notchat is an unofficial WhatsApp client for macOS with local AI. It shows chats, lets the user reply from the notch or from system notifications, can auto-reply to all, selected or no chats and groups, and has its own assistant chat that can read chats, search the web, read attached files and send a message to a contact when asked. Success: replying takes seconds, the app stays light and fast, and nothing leaves the machine unless the user asks.

## Positioning

Everything runs locally: the AI is whatever the user already has installed (Ollama, LM Studio, llama.cpp) or a llama.cpp the app sets up with one button. No accounts, no telemetry, no servers.

## Operating Context

Always running in the background on a MacBook, mostly glanced at through the notch; the main window is opened for longer conversations, the assistant chat and settings. First run is linking the phone by scanning a QR code generated by the app.

## Capabilities and Constraints

- Linking by QR or pair code; text send/receive; media shown as labelled placeholders for now.
- AI provider and model picker from what is installed; managed llama.cpp with a curated list of lightweight models.
- Auto-reply: All / Selected / None, separate for chats and groups, off by default, global kill switch.
- Assistant chat ("Notchat AI") is not a WhatsApp chat; sending to a contact shows a confirmation card unless the user turns confirmation off.
- Notifications: toggle between notch panel and system notifications, both with inline reply. Muted and archived chats never notify.
- Unofficial client: must say so, must warn that automation can get a number banned, must not use the WhatsApp name or marks.
- No claim of ISO 27001 / SOC 2 certification; controls are documented as "aligned, not certified".

## Brand Commitments

Name: Notchat. Minimalist and good-looking were explicitly requested. One accent colour, system typography, light and dark.

## Evidence on Hand

No screenshots, testimonials, benchmarks or user numbers exist. None may be invented.

## Product Principles

1. Local first: the user's messages never leave the Mac unless they ask.
2. Fast and light before feature-rich.
3. The AI never acts on a third party without the user having decided it.
4. Honest about being unofficial and about risk.
5. Quiet by default: the interface recedes, the conversation leads.

## Accessibility & Inclusion

WCAG AA contrast, full keyboard navigation, `prefers-reduced-motion` respected, all text through ES/EN localisation.
